# MucknSpark
MucknSpark is a rogue like rpg 2D game that incorporates the wave systems like those games in the arcade. It spawns the player who can dodge as well as slash 
the enemies to defend himself and he has to survive as many waves as he can until all of his flesh get's hacked by the goblins. 

I've taken the relentless, wave-based gauntlet of classic arcade cabinets and injected it with modern hack and slash feeling combat mechanics. You are dropped into an endless meat-grinder of goblin hordes. Your only objective? Survive, slaughter, and rack up the waves before they inevitably hack you to pieces.

<h1>Controls:</h1>

1. A and D are the primary controls for movement on the path.
2. Player can press J to cleave the goblins
3. Player can press the K button to roll through the enemies, avoiding any damage if the timing is perfect.

**Inspiration:** This game is inspired by games like hollow knight and classic rogue like games on arcade machines, it. Using HTML, CSS, JS and canvas on this was
a challenge i faced, particularly while making the cleave attack. Usually the player cannot avoid the enemies in these type of games but i made it such that
there is an option of dodging through every wave depending on the playstyle of the player.

I really love devil may cry 5 games as well and since i have played hollow knight i really wanted to add the slash mechanic to the game and make it feel awesome

**Theme: Indie Gamedev**<br>
I think the game suits this theme because it was made solely using HTML, CSS, JS and canvas without the use of any external game engine and is still enjoyable with
the potential for replayability and it also does not have a specific budget assigned to it, so it fits the theme perfectly.
